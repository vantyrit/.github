# Getting Help

This page explains where to go for different kinds of questions about Vantyr projects.

## Questions about using a project

1. Read the repository README and any documentation it links to.
2. Search the repository's existing issues. Your question may already have an answer.
3. If you still need help, open an issue in the relevant repository and describe what you tried and what you expected to happen.

## Bugs and feature requests

Please open an issue in the repository the problem relates to and fill in the template. Clear reproduction steps make a fix much faster.

## Security vulnerabilities

Do not open a public issue. Follow the private reporting steps in [SECURITY.md](SECURITY.md).

## Contributing

If you would like to contribute a fix or feature, start with [CONTRIBUTING.md](CONTRIBUTING.md).

## Business and other inquiries

For partnerships, licensing questions, or anything that does not belong in a public issue, email im@sourav.com.bd.
